# Spotify Wrapper
This is a wrapper for spotify that provides a custom shuffle algorithm.

## Setup
1. Clone the repository
2. Make sure you have Python installed (this project was written in version 3.12.2)
3. Run `pip install -r requirements.txt` to install the necessary modules
4. Create a .env file with the client id, client secret, and redirect url from the spotify developer dashboard
5. Run app.py and follow the instructions for authentication in the terminal.
